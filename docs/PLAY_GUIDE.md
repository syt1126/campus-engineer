# 试玩与操作

## 路线

1. 在开始菜单选简中、繁中或英文，选择开始新体验。
2. 推开教室门，在讲台拿取数据板。
3. 检查占用、温度和光照三个传感器；证据会记入工程记录。
4. 到控制终端修改规则。第一段观察占用条件，第二段处理光照波动，第三段检验“全部关闭”的反例。
5. 在独立场景复核方案，查看实验轨迹与成果导出。

不需要靠快速反应通关。规则的好坏由模拟结果判断；能耗和传感器数值是教学模拟，不是真实建筑控制标准。

## 自由探索

纸飞机会沿轨迹飞行后返回；木琴有八个音符，连续探索不同琴键可解锁发现；浇水壶倾斜后水滴落下、花朵展开；风铃会摆动并回应鸟鸣。另有三个隐藏纸星星，共七项发现。

按 J 打开手账。已经记录的发现不会重复累计；重新进入时恢复已保存的发现。它们不是教学主线的通关要求。

## 设置与存档

Esc 打开暂停，可保存、选择语言、调整音量和视角，或切换固定视点点击模式。固定视点模式的上方按钮可以前往传感器、终端、小浣熊、纸飞机、木琴和花盆附近。

进度写入 Unity 的 `Application.persistentDataPath/campus-save.json`，语言选项由 PlayerPrefs 保存。没有账号登录、云端同步或学生身份资料收集；导出文件可能包含玩家自己的实验记录，分享前请自行检查。

## 常见情况

- 编辑时空场景：正常，点击 Play 生成环境。
- 公开源码缺少柜子、投影仪等小道具：可选 Asset Store 资源未公开分发，参见 [ASSETS](ASSETS.md)。
- 鼠标不方便操作：Esc 切换固定视点点击模式。
- 想停止试玩：Esc → 离开游戏，或正常关闭窗口。
- 中文显示缺字：当前从系统加载 Microsoft JhengHei / Microsoft YaHei 等字体，未附带商业字体文件；Windows 是当前主要验证平台。

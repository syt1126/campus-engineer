# 产品与学习设计

## 要解决的问题

仅让学生阅读知识说明或点击答案，容易把交互变成包装过的练习题。本项目尝试把控制规则放回具体场景：看见设备运行、找到证据、提出方案、观察失败，再修改解释。

香港校园、三语界面和固定视点模式是当前设计方向。目标用户是中小学学生，具体年级、课程难度和授课时长仍需教师与学生试点确认。

## 主循环

观察异常 → 收集证据 → 形成假设 → 调整规则 → 模拟实验 → 用反例复核 → 保存结果。

| 场景问题 | 当前实现 | 希望学生理解 |
| --- | --- | --- |
| 空教室仍在运行 | 占用条件修复 | 单一温度条件不够，需要组合条件 |
| 灯光反复切换 | 带噪光照与迟滞 | 临界值附近需要考虑稳定性 |
| 全部关闭是否最好 | 全关反例与服务要求 | 指标优化必须满足约束 |

系统保留实验轨迹，既看最终是否通过，也呈现错误方案如何产生反例。当前数值是可复现的教学模型，不用于指导真实校园设备控制。

## 兴趣与节奏

角色、暖色环境和连续物件动画帮助建立熟悉感。课间互动以短时、无惩罚、可自由退出为原则；可选发现与学习主线分开，不要求学生先收集才能继续学习。

## AI 的位置

当前向导使用离线预设提示，避免把未经验证的在线生成建议包装为既定功能。下一阶段先研究分层提示、教师控制、错误建议的检验和隐私边界，再考虑模型接入。

## 需求验证计划

优先邀请少量目标学生与辅导教师进行观察式试用，记录是否愿意主动互动、能否解释自己的规则、遇到哪些操作障碍。再访谈机构是否需要课堂部署、教师记录与课程配置；当前没有已验证付费客户或学习效果数据。
